HOW TO PREVIEW
1. Extract this ZIP on your computer.
2. Open index.html in Chrome or Edge (pages link to each other).
3. If security settings restrict local files, upload the contents to a test
   website or serve them locally through any basic static web server.
4. Test on desktop and mobile before replacing the current live website.

HOW TO PUBLISH ON YOUR .COM.NP DOMAIN
1. FIRST DOWNLOAD A BACKUP of your existing website and related files from
   your host / cPanel File Manager.
2. Check the correct document root for omshreeart.com.np, usually public_html.
3. Upload the CONTENTS of the extracted website folder (not its outer folder).
4. Ensure index.html is at the document root.
5. Check all pages, WhatsApp number, email, maps link, quote form and service
   descriptions before letting customers use it.
6. Refresh your browser cache or CDN cache if old styling persists.
7. Keep any important pre-existing files or backend integrations separately.
